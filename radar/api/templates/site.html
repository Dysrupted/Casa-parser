How this works
  • Collected daily by Casa Radar, an open-source personal monitor. Each row links to the original ad; contact sellers there.
  • Mubawab allows only the first page of each neighbourhood search to be crawled, so it contributes the ~30 newest or promoted listings per neighbourhood each day. Avito is read across Casablanca, newest first, and filtered to these zones. Rentals posted as sales are removed.
  • "vs zone" is a listing's price per m² divided by its zone's median. Under 1.00 means cheaper than the typical asking price there.
  • The same flat advertised on both sites is shown once.
  • EUR uses the day's EUR/MAD rate ({{ meta.eur_mad_label }}).
