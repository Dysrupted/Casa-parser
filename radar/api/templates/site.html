How this is collected
  • Collected daily by Casa Radar from Mubawab and Avito. Each listing links to the original ad, where sellers can be contacted.
  • Mubawab allows only the first page of each neighbourhood search to be read, so it contributes its ~30 newest or promoted listings per zone each day. Avito is read across Casablanca, newest first, and filtered to these zones. Rentals posted as sales are removed, and a flat advertised on both sites appears once.
  • These are sellers’ asking prices, not sale prices. EUR amounts use the day’s rate ({{ meta.eur_mad_label }}).
